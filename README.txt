comment faire marcher le code:

1- si vous êtes sous Windows vous aurez possiblement besoin des drivers pour que votre pc reconnaisse le lidar
	dans ce cas la installer les driver correspondant disponible sur le site du fabriquant du lidar.

2- brancher le lidar dans un port USB du pc et regarder le nom du port.

3- dans le code :"code_final_detection_position_robot_lidar.py" ligne 12 mettre le bon port.

3- lancer ce même code.
